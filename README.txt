RUSHDA SAIYED — LUXURY PORTFOLIO

1. Open index.html in your browser.
2. Replace the placeholder email and social links in index.html.
3. Replace project links (#) with your Figma/GitHub/Behance URLs.
4. Replace the CSS mockups with screenshots of your actual projects when ready.
5. Upload the folder to GitHub Pages, Netlify or another static hosting service.

The design uses Google Fonts (Cormorant Garamond + Manrope), so an internet connection is needed for the fonts unless you self-host them.
